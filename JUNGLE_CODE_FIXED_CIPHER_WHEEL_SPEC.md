# Jungle Code — исправление механики шифровального колеса

## 1. Цель изменения

Необходимо изменить механику расшифровки вопросов в **Jungle Code**.

Игрок должен вращать внутреннее кольцо только в начале задания — чтобы найти правильное соответствие для **первой буквы фразы**. После правильной настройки положение колец фиксируется. Все остальные буквы игрок расшифровывает, сопоставляя символы внешнего и внутреннего колец, без повторного вращения механизма.

Механика должна напоминать приложенный референс, но визуально оставаться частью Expedition Vault: темный древний камень, бронзово-золотые элементы, мох, резные узоры и приглушенное зелено-золотое свечение.

## 2. Основной игровой цикл

```text
Show encrypted question
        ↓
Select the first encrypted letter
        ↓
Rotate the inner ring
        ↓
Find the correct first decoded letter
        ↓
Confirm wheel alignment
        ↓
Lock both rings in position
        ↓
Decode all remaining letters by matching the two alphabets
        ↓
Check the completed phrase
        ↓
Receive the rune
```

## 3. Что показывается на экране

Игровой экран состоит из четырех основных областей.

### 3.1. Каменная табличка с вопросом

В верхней части находится древняя каменная или пергаментная табличка.

На ней отображаются:

- номер сообщения: **ANCIENT MESSAGE 1 / 3**;
- зашифрованный вопрос;
- подсказка уровня сложности;
- состояние механизма: **ALIGN THE FIRST LETTER** или **WHEEL LOCKED**.

Пример:

```text
ANCIENT MESSAGE 1 / 3

ZKHUH GLG BRX JR WKLV VXPPHU?

ALIGN THE FIRST LETTER
```

Первая зашифрованная буква должна быть визуально выделена золотой рамкой.

### 3.2. Шифровальное колесо

Под табличкой располагается большое каменное колесо из двух концентрических колец.

Внешнее кольцо:

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

Внутреннее кольцо:

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

До настройки внутреннее кольцо можно вращать. Внешнее кольцо всегда остается неподвижным.

Все 26 букв должны располагаться по окружности отдельно и быть хорошо читаемыми. Не следует выводить алфавит одной строкой внутри круга.

### 3.3. Поле расшифровки

Рядом с колесом или под ним отображается строка с отдельными ячейками:

```text
[ _ ][ _ ][ _ ][ _ ][ _ ]   [ _ ][ _ ][ _ ] ...
```

Каждая ячейка соответствует одной букве исходного вопроса.

- пробелы показываются автоматически;
- знаки препинания показываются автоматически;
- первая буква открывается после правильной настройки колеса;
- остальные буквы игрок вводит самостоятельно.

### 3.4. Панель действий

До фиксации колеса:

- кнопка поворота влево;
- кнопка поворота вправо;
- текущий сдвиг, если это разрешено уровнем сложности;
- кнопка **LOCK ALIGNMENT**.

После фиксации:

- кнопки вращения блокируются или исчезают;
- появляется статус **WHEEL LOCKED**;
- становится доступным ввод остальных букв;
- появляется кнопка **CHECK MESSAGE**.

## 4. Настройка по первой букве

В начале задания активна только первая буква зашифрованной фразы.

Например:

```text
Encrypted letter: Z
Decoded letter: W
```

Игрок вращает внутреннее кольцо, пока буква `Z` на одном кольце не окажется напротив буквы `W` на другом кольце.

После этого игрок нажимает:

> **LOCK ALIGNMENT**

### Правильная настройка

Если первая пара букв выбрана правильно:

1. первая расшифрованная буква автоматически появляется в поле ответа;
2. внутреннее кольцо фиксируется;
3. кнопки вращения блокируются;
4. вокруг центральной оси появляется слабое зелено-золотое свечение;
5. проигрывается звук фиксации тяжелого каменного механизма;
6. появляется сообщение:

   > **The cipher is aligned. Follow the rings.**

### Неправильная настройка

Если первая пара выбрана неправильно:

- кольцо не блокируется;
- первая буква не открывается;
- механизм слегка вздрагивает;
- проигрывается приглушенный звук каменного удара;
- показывается сообщение:

  > **The first letter does not align. Turn the wheel again.**

Игрок может продолжить вращение без потери прогресса.

## 5. Фиксированное положение колец

После правильной настройки внутреннее кольцо нельзя вращать до завершения текущего вопроса.

Необходимо заблокировать:

- drag-and-drop вращение;
- Pointer Events для вращения;
- кнопки поворота;
- клавиши `ArrowLeft` и `ArrowRight`;
- колесо мыши, если оно поддерживало вращение.

В состоянии блокировки необходимо добавить класс:

```js
cipherWheel.classList.add('locked');
```

Минимальное состояние задания:

```js
const state = {
  selectedShift: 0,
  wheelLocked: false,
  activeLetterIndex: 0,
  decodedLetters: []
};
```

Проверка перед любым вращением:

```js
function rotateInnerRing(direction) {
  if (state.wheelLocked) return;

  state.selectedShift =
    (state.selectedShift + direction + 26) % 26;

  renderInnerRing();
  playStoneStep();
}
```

## 6. Расшифровка остальных букв

После фиксации игрок использует колесо как таблицу соответствий.

Для каждой зашифрованной буквы игрок:

1. находит ее на внешнем кольце;
2. смотрит, какая буква внутреннего кольца расположена напротив нее;
3. вводит найденную букву в текущую ячейку;
4. переходит к следующей букве.

Кольца при этом остаются неподвижными.

Поддержать два способа ввода:

- физическая клавиатура;
- экранная клавиатура `A–Z` для мыши и мобильных устройств.

Игрок также может нажать на незаполненную ячейку, чтобы вернуться к ней и изменить ответ до окончательной проверки сообщения.

## 7. Проверка ответа

Кнопка **CHECK MESSAGE** становится активной только после заполнения всех буквенных ячеек.

### Правильная фраза

Если вопрос расшифрован правильно:

- все ячейки получают слабую зелено-золотую подсветку;
- показывается исходный английский вопрос;
- появляется надпись **MESSAGE DECODED**;
- игрок отвечает на вопрос устно;
- становится доступна кнопка **CLAIM RUNE**.

### Ошибки во фразе

Если некоторые буквы неправильные:

- правильные буквы остаются на месте;
- неправильные ячейки получают приглушенную красную рамку;
- содержимое неправильных ячеек очищается;
- активной становится первая неправильная ячейка;
- положение колец остается зафиксированным;
- повторно настраивать колесо не нужно.

Сообщение:

> **Some letters do not follow the rings. Try again.**

## 8. Три уровня сложности

Механика фиксации колеса одинакова на всех уровнях. Различаются длина вопроса и объем подсказок.

| Сложность | Вопрос | Сдвиг | Помощь с первой буквой |
|---|---|---:|---|
| Easy | 4–7 слов | 1–3 | Показаны первая расшифрованная буква и точный сдвиг |
| Medium | 7–11 слов | 4–7 | Показана первая расшифрованная буква, сдвиг скрыт |
| Hard | 10–16 слов | 8–15 | Дается смысловая подсказка, первую букву игрок определяет сам |

Для Hard можно добавить кнопку **REVEAL FIRST LETTER**, но ее использование должно визуально отмечаться как подсказка.

## 9. Визуальный стиль

Референс используется для композиции и принципа взаимодействия, но не копируется буквально.

### Фон

- древний темный каменный механизм;
- глубокие зеленые и почти черные оттенки;
- мох и тонкие корни по краям;
- едва заметная дымка;
- виньетка по краям экрана.

### Колесо

- массивные концентрические каменные кольца;
- бронзовые разделители между буквами;
- выгравированные английские буквы;
- потертые края и мелкие трещины;
- золотой указатель текущей пары букв;
- мягкая подсветка выбранного соответствия;
- никакого чистого белого пластика, как в референсе.

### Табличка с вопросом

- темная каменная плита или старый потемневший пергамент;
- тонкая золотистая рамка;
- английский текст светлого песочного цвета;
- первая буква выделена золотым;
- без современных ярких элементов интерфейса.

### Состояние блокировки

После правильной настройки:

- элементы вращения становятся темнее;
- по внутреннему кольцу проходит слабая световая волна;
- текущая пара букв отмечается зелено-золотым маркером;
- появляется небольшая надпись **WHEEL LOCKED**;
- подсветка должна быть сдержанной, без яркого неонового зеленого цвета.

## 10. Звуки

До фиксации:

- каждый шаг кольца сопровождается коротким звуком двигающегося камня;
- звук проигрывается только при переходе на следующий буквенный сектор;
- между звуками сохраняется ограничение 60–90 мс.

При правильной фиксации:

- тяжелый каменный щелчок;
- короткий низкий гул механизма.

После фиксации звуки вращения больше не проигрываются, потому что колесо заблокировано.

## 11. Доступность и адаптивность

- буквы обоих колец должны оставаться читаемыми на небольших экранах;
- на мобильных устройствах колесо располагается над полем ответа;
- размер интерактивных кнопок — не менее `44 × 44 px`;
- активная ячейка имеет не только цветовое выделение, но и заметную рамку;
- статус блокировки передается через текст, а не только через цвет;
- колесо имеет понятный `aria-label`;
- после фиксации фокус автоматически переносится на первую пустую ячейку или экранную клавиатуру.

## 12. Критерии готовности

- [ ] В начале вопроса вращается только внутреннее кольцо.
- [ ] Внешнее кольцо всегда остается неподвижным.
- [ ] Игрок настраивает колесо по первой букве фразы.
- [ ] Неправильная первая буква не блокирует механизм.
- [ ] Правильная первая буква фиксирует положение обоих колец.
- [ ] После фиксации кольцо нельзя повернуть мышью, касанием, кнопками или клавиатурой.
- [ ] Первая расшифрованная буква открывается автоматически.
- [ ] Остальные буквы вводятся путем сопоставления двух неподвижных алфавитов.
- [ ] На экране присутствует клавиатура `A–Z`.
- [ ] Пробелы и знаки препинания отображаются автоматически.
- [ ] **CHECK MESSAGE** доступна только после заполнения всех букв.
- [ ] Ошибочная проверка очищает только неправильные буквы.
- [ ] После ошибки кольцо остается правильно зафиксированным.
- [ ] После правильной расшифровки появляется **CLAIM RUNE**.
- [ ] Композиция напоминает референс, но оформлена в каменно-золотой стилистике Expedition Vault.
- [ ] Подсветка сдержанная и не выглядит ярко-зеленой или неоновой.
