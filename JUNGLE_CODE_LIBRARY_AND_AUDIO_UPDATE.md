# Jungle Code — расширение библиотеки заданий и звуковое оформление

Этот документ дополняет основную механику квеста **Jungle Code**. Изменения касаются библиотеки шифров, поведения игры после ошибки и звукового сопровождения.

## 1. Большая библиотека заданий

Для каждого этапа и каждого уровня сложности должна использоваться большая библиотека однотипных заданий. Если игрок ошибается, он получает **другое задание того же типа и той же сложности**, а не повторяет прежнее.

### Структура библиотеки

В квесте три этапа, соответствующие трем рунам:

1. **Sun Rune**
2. **Eye Rune**
3. **Spiral Rune**

Для каждого этапа создается отдельный набор сообщений на каждом уровне сложности:

- `easy.sun`, `easy.eye`, `easy.spiral`;
- `medium.sun`, `medium.eye`, `medium.spiral`;
- `hard.sun`, `hard.eye`, `hard.spiral`.

Рекомендуемый минимальный объем библиотеки — **20 заданий для каждой комбинации этапа и сложности**. Общий минимальный объем составляет 180 заданий:

`3 этапа × 3 уровня сложности × 20 заданий = 180 заданий`.

Каждое задание должно содержать:

```js
{
  id: "easy-sun-01",
  difficulty: "easy",
  rune: "sun",
  encryptedMessage: "...",
  decodedMessage: "...",
  shift: 3,
  hint: "..."
}
```

### Поведение после ошибки

Если игрок нажимает **UNLOCK MESSAGE** и вводит неправильный ответ:

1. Показывается короткое сообщение:

   > The runes remain silent. Another message is awakening...

2. Проигрывается мягкий звук ошибки.
3. Текущее задание помечается использованным.
4. Через 700–1000 мс появляется **новое случайное задание**:
   - с того же этапа;
   - с тем же уровнем сложности;
   - с той же целевой руной;
   - с другим `id`.
5. Положение колец возвращается в исходное состояние для нового задания.
6. Уже полученные руны, пройденные этапы и общий прогресс игрока не сбрасываются.

Игрок не должен снова получить то же задание, пока не будут использованы все задания текущего набора. После исчерпания набора список использованных заданий можно очистить, при этом последнее показанное задание не должно выбираться повторно сразу.

Пример выбора следующего задания:

```js
function getNextChallenge(difficulty, rune, currentId) {
  const pool = challengeLibrary[difficulty][rune];
  const unused = pool.filter(
    (challenge) =>
      challenge.id !== currentId &&
      !sessionState.usedChallengeIds.has(challenge.id)
  );

  if (unused.length === 0) {
    pool.forEach((challenge) => {
      if (challenge.id !== currentId) {
        sessionState.usedChallengeIds.delete(challenge.id);
      }
    });

    return getNextChallenge(difficulty, rune, currentId);
  }

  return unused[Math.floor(Math.random() * unused.length)];
}
```

## 2. Музыка квеста

При входе в **Jungle Code** должна начинать играть музыка из файла:

```text
music2.mp3
```

### Требования к воспроизведению

- музыка запускается при открытии квеста;
- трек воспроизводится циклически через `loop`;
- при нажатии **ENTER JUNGLE CODE** воспроизведение гарантированно запускается как результат действия пользователя;
- если браузер заблокировал автоматическое воспроизведение, музыка начинается после первого клика или нажатия клавиши;
- при выходе из квеста, возврате в главное меню или закрытии страницы музыка останавливается;
- желательно использовать плавное появление и затухание звука продолжительностью 500–800 мс;
- игрок может включать и выключать музыку, а также менять ее громкость;
- выбранные громкость и состояние `mute` сохраняются в `localStorage`;
- музыка квеста не должна одновременно играть с музыкой главного меню или другого квеста.

Пример:

```html
<audio id="jungle-code-music" src="music2.mp3" preload="auto" loop></audio>
```

```js
const music = document.querySelector("#jungle-code-music");

music.volume = Number(
  localStorage.getItem("jungleCodeMusicVolume") ?? 0.35
);
music.muted = localStorage.getItem("jungleCodeMusicMuted") === "true";

async function startJungleCodeMusic() {
  try {
    await music.play();
  } catch {
    document.addEventListener("pointerdown", () => music.play(), { once: true });
  }
}

function stopJungleCodeMusic() {
  music.pause();
  music.currentTime = 0;
}
```

## 3. Звуки двигающегося камня

При вращении каждого каменного кольца должен проигрываться звук движения тяжелого древнего механизма.

### Звуковое поведение

- при начале перетаскивания воспроизводится тихий звук трения камня;
- при прохождении каждого фиксированного шага кольца звучит короткий каменный щелчок;
- при отпускании кольца воспроизводится более плотный звук фиксации;
- вращение кнопками или клавиатурой также сопровождается одним каменным щелчком на каждый шаг;
- соседние кольца могут иметь немного разную высоту звука, чтобы механизмы различались на слух;
- звуки не должны перекрывать музыку и быть громче нее;
- все эффекты подчиняются общей настройке звука и отдельной громкости `SFX`;
- при выключенном звуке эффекты не воспроизводятся.

Рекомендуемые названия файлов, если будут добавлены готовые эффекты:

```text
stone-ring-drag.mp3
stone-ring-step.mp3
stone-ring-lock.mp3
```

Если отдельных аудиофайлов пока нет, временный каменный щелчок можно создать через Web Audio API. Нельзя создавать новый `AudioContext` на каждое движение: контекст и аудиобуферы должны переиспользоваться.

### Защита от слишком частого воспроизведения

Событие `pointermove` вызывается слишком часто, поэтому звук нельзя запускать при каждом пикселе движения. Он проигрывается только тогда, когда кольцо действительно переходит на следующий фиксированный сектор.

```js
function rotateRingToStep(ring, nextStep) {
  if (ring.currentStep === nextStep) return;

  ring.currentStep = nextStep;
  renderRing(ring);
  playStoneStep(ring.index);
}
```

Для дополнительной защиты между звуками одного кольца должен соблюдаться интервал не менее 60–90 мс.

## 4. Баланс громкости

Рекомендуемые исходные значения:

- музыка `music2.mp3`: `35%`;
- трение камня: `15%`;
- шаг кольца: `22%`;
- фиксация кольца: `28%`;
- звук правильного ответа: `30%`;
- звук ошибки: `20%`.

Настройки звука должны быть доступны внутри квеста без выхода в главное меню.

## 5. Критерии готовности

- [ ] Для каждой сложности и каждого этапа подключена отдельная библиотека заданий.
- [ ] После неправильного ответа появляется другое задание того же типа и сложности.
- [ ] Новое задание не повторяет предыдущее и не сбрасывает полученные руны.
- [ ] В одной игровой сессии задания не повторяются до исчерпания соответствующего набора.
- [ ] `music2.mp3` запускается при входе в Jungle Code и играет циклически.
- [ ] Музыка останавливается при выходе из квеста.
- [ ] Работают включение, выключение и регулировка громкости музыки.
- [ ] При вращении колец слышно движение камня и фиксацию сектора.
- [ ] Звуки не запускаются на каждый пиксель движения и не создают аудиошум.
- [ ] Все настройки звука сохраняются и корректно восстанавливаются.
