# Jungle Code — инструкция по реализации второго квеста

## 1. Концепция

**Jungle Code** — второй образовательный квест Expedition Vault.

Игрок расшифровывает три древних послания с помощью интерактивного механизма, основанного на **Caesar Cipher**, получает три магические руны и устанавливает их в правильном порядке в древний камень.

Тематика языкового контента:

- summer;
- summer holidays;
- experiences;
- memories;
- первые занятия нового учебного года.

Поддерживаемые уровни: **ESL A2–C1**.

Квест не должен выглядеть как обычный multiple-choice тест. Центральная игровая механика — вращение каменного шифровального диска и наблюдение за изменением букв.

## 2. Общая цель

Игрок должен:

1. войти в Jungle Code;
2. выбрать уровень сложности;
3. расшифровать три английских сообщения;
4. после каждого сообщения устно ответить на вопрос;
5. получить три разные руны;
6. перейти в Rune Chamber;
7. вспомнить порядок получения рун;
8. установить руны в правильные слоты;
9. активировать древний камень;
10. сохранить прогресс;
11. вернуться на главную страницу.

## 4. Стартовый экран

Заголовок:

> **JUNGLE CODE**

Вводный текст:

> **Three messages lie sealed within the ancient stone. Decode them, recover the runes and awaken the jungle path.**

Кнопка:

> **ENTER JUNGLE CODE**

## 5. Выбор сложности

Перед началом игрок выбирает один уровень на всё прохождение:

| Сложность | Уровень ESL | Сдвиг |
|---|---|---:|
| Easy | A2–B1 | 1–3 |
| Medium | B1–B2 | 4–7 |
| Hard | B2–C1 | 8–15 |

Игрок проходит только выбранный уровень. В одном прохождении всегда используются три сообщения.

## 6. Правила Caesar Cipher

Использовать только английский алфавит `A–Z`.

Каждая буква исходного текста заменяется буквой, расположенной на определённое количество позиций дальше по алфавиту.

При сдвиге `+3`:

```text
A → D
B → E
C → F
...
X → A
Y → B
Z → C
```

Пример:

```text
SUMMER → VXPPHU
```

Правила обработки текста:

- шифровать только латинские буквы;
- сохранять пробелы;
- сохранять знаки препинания;
- сохранять вопросительные знаки;
- поддерживать циклический переход `Z → A`;
- выводить игровые сообщения в верхнем регистре.

## 7. Функции шифрования

Зашифрованные строки генерируются автоматически. Не хранить вручную исходный и зашифрованный варианты одного сообщения.

```javascript
const ALPHABET = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

function encodeCaesar(text, shift) {
  return text.toUpperCase().replace(/[A-Z]/g, letter => {
    const index = ALPHABET.indexOf(letter);
    return ALPHABET[(index + shift) % 26];
  });
}

function decodeCaesar(text, shift) {
  return encodeCaesar(text, (26 - shift) % 26);
}
```

Для отображения результата текущего положения колеса:

```javascript
const preview = decodeCaesar(encodedMessage, selectedShift);
```

## 8. Интерактивное шифровальное колесо

Центральный элемент интерфейса — большой круглый древний каменный механизм с двумя кольцами букв.

### Внешнее кольцо

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

### Внутреннее кольцо

Содержит тот же алфавит, но поворачивается относительно внешнего кольца.

Пример для сдвига `+3`:

```text
DEFGHIJKLMNOPQRSTUVWXYZABC
```

### Управление

Игрок может:

- перетаскивать внутреннее кольцо мышью;
- вращать его пальцем;
- использовать кнопки поворота влево и вправо;
- использовать клавиши `ArrowLeft` и `ArrowRight`;
- видеть текущий декодированный текст после каждого шага.

Каждый шаг поворота изменяет выбранный сдвиг на одну букву.

Диапазон:

```text
0–25
```

После `25` колесо возвращается к `0`.

## 9. Структура одного задания

### Верхняя часть

Показать номер:

> **ANCIENT MESSAGE 1 / 3**

### Центр

Показать зашифрованную строку:

> **ZKDW ZDV WKH EHVW SDUW RI BRXU VXPPHU?**

### Ниже

- интерактивное колесо Caesar Cipher;
- автоматически обновляемую расшифровку;
- подсказку, зависящую от сложности.

### Кнопка проверки

> **UNLOCK MESSAGE**

## 10. Easy — A2–B1

Использовать:

- короткие вопросы;
- простую лексику;
- знакомые темы;
- сдвиг 1–3;
- прямую подсказку.

Подсказки:

> **SHIFT: 3**

или:

> **Move each letter 3 places back.**

Сообщения:

```text
WHERE DID YOU GO THIS SUMMER?
WHAT WAS YOUR BEST SUMMER DAY?
WHAT DID YOU DO FOR FUN?
```

## 11. Medium — B1–B2

Использовать:

- более длинные вопросы;
- лексику B1–B2;
- вопросы с развёрнутым ответом;
- сдвиг 4–7;
- подсказку без точного числа.

Подсказка:

> **The letters have moved through the alphabet. Find the shift.**

Сообщения:

```text
WHAT WAS THE MOST MEMORABLE PART OF YOUR SUMMER?
DID YOU TRY SOMETHING NEW THIS SUMMER?
WHAT WOULD YOU CHANGE ABOUT YOUR SUMMER IF YOU COULD?
```

## 12. Hard — B2–C1

Использовать:

- длинные вопросы;
- advanced vocabulary;
- абстрактные темы;
- аргументацию;
- сдвиг 8–15;
- отсутствие прямой подсказки.

Сообщения:

```text
WHICH SUMMER EXPERIENCE CHANGED YOUR PERSPECTIVE THE MOST?
WHAT IS SOMETHING YOU WISH YOU HAD DONE DIFFERENTLY THIS SUMMER?
IF YOU COULD RELIVE ONE MOMENT FROM THIS SUMMER, WHICH WOULD YOU CHOOSE AND WHY?
```

## 13. Проверка ответа

При нажатии **UNLOCK MESSAGE** проверить, совпадает ли выбранный игроком сдвиг с правильным значением.

Дополнительно можно сравнить текущую строку с исходным сообщением:

```javascript
const solved =
  selectedShift === message.shift &&
  currentPreview === message.text.toUpperCase();
```

### Неправильный сдвиг

- не сбрасывать текущий прогресс;
- не переходить к следующему сообщению;
- слегка встряхнуть диск;
- погасить подсветку рун;
- показать короткую вспышку.

Сообщение:

> **The runes remain silent. Try another shift.**

Игрок может продолжать вращать диск и повторить проверку.

### Правильный сдвиг

1. зашифрованный текст превращается в исходную английскую фразу;
2. фраза начинает светиться;
3. появляется руна текущего сообщения;
4. проигрывается магический эффект;
5. колесо временно блокируется.

Заголовок:

> **MESSAGE DECODED**

Инструкция:

> **Answer the question.**

Система не проверяет устный ответ студента.

После устного ответа нажимается:

> **CLAIM RUNE**

## 14. Три руны

Использовать три визуально различающихся символа:

| Сообщение | Руна | Символика |
|---:|---|---|
| Message 1 | Rune A | Солнце |
| Message 2 | Rune B | Глаз |
| Message 3 | Rune C | Спираль |

Руны должны различаться:

- формой;
- внутренним рисунком;
- свечением;
- подписью для доступности.

Прогресс:

```text
RUNES

◆ ◇ ◇
◆ ◆ ◇
◆ ◆ ◆
```

Желательно показывать изображения найденных рун вместо одинаковых ромбов.

## 15. Получение руны

При нажатии **CLAIM RUNE**:

1. руна перемещается в панель прогресса;
2. сохраняется связь с номером сообщения;
3. увеличивается счётчик;
4. открывается следующее сообщение.

После третьей руны показать:

> **ALL RUNES RECOVERED**

Затем:

> **The Jungle Code awaits.**

Кнопка:

> **ENTER THE RUNE CHAMBER**

## 16. Rune Chamber

Игрок оказывается перед большим древним круглым камнем.

В центре находятся три пустых слота:

```text
[ SLOT 1 ] [ SLOT 2 ] [ SLOT 3 ]
```

Рядом находятся три найденные руны.

Перед показом руны необходимо перемешать:

```javascript
const shuffledRunes = shuffle(collectedRunes);
```

Порядок в панели не должен подсказывать правильную последовательность.

## 17. Правильный порядок

Правильный порядок определяется сообщениями:

```text
Slot 1 → Rune A → Message 1
Slot 2 → Rune B → Message 2
Slot 3 → Rune C → Message 3
```

Игрок должен вспомнить последовательность получения рун.

Руны разрешается устанавливать в слоты в любом порядке, но каждая руна принимается только своим слотом.

## 18. Drag-and-drop рун

Поддержать:

- мышь;
- Pointer Events;
- touch-управление;
- клавиатуру.

При перетаскивании правильной руны в правильный слот:

- руна примагничивается;
- слот начинает светиться;
- руна блокируется;
- прогресс увеличивается.

При неправильном слоте:

- слот кратко вспыхивает;
- камень отвергает руну;
- руна возвращается в исходную область;
- остальные установленные руны остаются на месте.

Сообщение:

> **The stone rejects this rune.**

Не показывать правильный ответ.

## 19. Активация древнего камня

После правильной установки всех трёх рун:

1. руны начинают светиться;
2. свет распространяется по резным символам;
3. кольца каменного механизма вращаются;
4. появляется зелёно-золотое свечение;
5. Jungle Code активируется.

Заголовок:

> **THE JUNGLE CODE IS COMPLETE**

Текст:

> **The ancient path has awakened.**

## 20. Завершение квеста

После активации сохранить:

```javascript
localStorage.setItem("jungleCodeCompleted", "true");
localStorage.setItem("jungleCodeRunesActivated", "true");
```

Добавить Jungle Code в общий список достижений:

```javascript
const achievements = JSON.parse(
  localStorage.getItem("expeditionAchievements") || "[]"
);

if (!achievements.includes("code")) {
  achievements.push("code");
}

localStorage.setItem(
  "expeditionAchievements",
  JSON.stringify(achievements)
);
```

Кнопка:

> **RETURN TO THE JUNGLE**

или:

> **BACK TO QUEST MAP**

Повторное прохождение не должно удалять ранее сохранённый прогресс.

## 23. Developer Mode

При активном Developer Mode разрешить переход:

- на стартовый экран;
- к выбору сложности;
- к любому сообщению `1–3`;
- к состоянию MESSAGE DECODED;
- в Rune Chamber;
- к сцене активированного камня.

Developer Mode не должен автоматически сохранять пользовательский прогресс.
