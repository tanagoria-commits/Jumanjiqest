# Jungle Code — исправленная механика квеста

## 1. Концепция

**Jungle Code** — второй квест Expedition Vault. Игрок должен пройти три последовательных раунда с шифром Цезаря, получить три древние руны и установить их в правильном порядке в каменное изваяние.

В каждом раунде игрок расшифровывает **один английский вопрос буква за буквой**. За каждый полностью расшифрованный вопрос выдается одна руна.

После получения всех трех рун игрок переносится в древний полуразрушенный зал. В центре зала находится каменное изваяние с тремя пустыми слотами. Игрок должен вспомнить порядок получения рун и правильно установить их в изваяние.

## 2. Игровой цикл

```text
Enter Jungle Code
        ↓
Choose difficulty
        ↓
Decode Question 1 letter by letter
        ↓
Receive rune1.png
        ↓
Decode Question 2 letter by letter
        ↓
Receive rune2.png
        ↓
Decode Question 3 letter by letter
        ↓
Receive rune3.png
        ↓
Enter the Ruined Hall
        ↓
Place all three runes in the correct order
        ↓
RETURN TO THE JUNGLE
        ↓
Main menu
```

## 3. Уровни сложности

Перед началом квеста игрок выбирает один из трех уровней сложности, как в Lost Temple.

| Сложность | Уровень английского | Длина вопроса | Сдвиг Цезаря | Подсказки |
|---|---|---|---:|---|
| Easy | A2–B1 | 4–7 слов | 1–3 | Показан размер сдвига и первая буква |
| Medium | B1–B2 | 7–11 слов | 4–7 | Показан диапазон сдвига |
| Hard | B2–C1 | 10–16 слов | 8–15 | Размер сдвига не показывается |

Выбранная сложность действует на все три раунда. При переходе к следующему вопросу сложность не меняется.

## 4. Структура прохождения

Квест состоит из трех раундов:

| Раунд | Задание | Награда |
|---:|---|---|
| 1 | Расшифровать один вопрос | `rune1.png` |
| 2 | Расшифровать один вопрос | `rune2.png` |
| 3 | Расшифровать один вопрос | `rune3.png` |

Внутри каждого раунда на экране находится только один текущий вопрос. Следующий вопрос появляется только после завершения предыдущего.

## 5. Расшифровка буква за буквой

Вопрос зашифрован шифром Цезаря и показан в верхней части игрового поля.

Пример исходного вопроса:

```text
WHERE DID YOU GO THIS SUMMER?
```

Пример при сдвиге `+3`:

```text
ZKHUH GLG BRX JR WKLV VXPPHU?
```

Под зашифрованной строкой необходимо показать ряд отдельных ячеек. Каждая ячейка соответствует одной букве исходного вопроса.

```text
[ W ][ H ][ E ][ R ][ E ]   [ D ][ I ][ D ] ...
```

Пробелы и знаки препинания отображаются сразу и не требуют ввода.

### Управление

Игрок:

1. выбирает текущую ячейку;
2. вращает каменное кольцо шифра Цезаря;
3. находит нужную расшифрованную букву;
4. подтверждает выбранную букву;
5. переходит к следующей ячейке.

Поддержать:

- кнопки поворота кольца влево и вправо;
- клавиши `ArrowLeft` и `ArrowRight`;
- ввод букв с физической клавиатуры;
- экранную клавиатуру для мобильных устройств;
- выбор ячейки мышью или касанием.

Текущая ячейка должна быть обведена золотой рамкой. Уже правильно расшифрованные буквы остаются открытыми.

## 6. Проверка букв

Каждая буква проверяется отдельно.

### Правильная буква

- буква фиксируется в ячейке;
- ячейка получает слабую зелено-золотую подсветку;
- проигрывается тихий звук каменной фиксации;
- активной становится следующая незаполненная ячейка.

### Неправильная буква

- буква не фиксируется;
- ячейка коротко подсвечивается приглушенным красным;
- уже открытые буквы не сбрасываются;
- игрок продолжает работу с той же ячейкой.

Сообщение:

> **The rune rejects this letter. Try again.**

Нельзя проверять весь вопрос одним нажатием кнопки. Основная механика должна ощущаться как постепенная расшифровка древней надписи.

## 7. Завершение вопроса

Когда заполнена последняя буква:

1. весь расшифрованный вопрос начинает мягко светиться;
2. появляется надпись:

   > **MESSAGE DECODED**

3. игроку предлагается прочитать вопрос и ответить на него устно;
4. появляется кнопка:

   > **CLAIM RUNE**

5. после нажатия показывается соответствующее изображение руны;
6. руна перемещается в панель прогресса;
7. начинается следующий раунд.

Устный ответ не проверяется системой.

## 8. Изображения рун

Использовать реальные файлы из корня проекта:

```text
rune1.png
rune2.png
rune3.png
```

Не заменять изображения текстовыми символами, эмодзи или CSS-фигурами.

В панели прогресса должны находиться три позиции:

```text
[ RUNE 1 ] [ RUNE 2 ] [ RUNE 3 ]
```

До получения руны показывается темный полупрозрачный силуэт. После получения в соответствующей позиции появляется полноцветное изображение.

Все изображения должны:

- сохранять исходные пропорции через `object-fit: contain`;
- иметь одинаковую визуальную высоту;
- не растягиваться;
- иметь слабое золотистое свечение после получения.

## 9. Переход в древний зал

После получения `rune3.png` показать сообщение:

> **ALL RUNES RECOVERED**

> **The ancient hall has opened.**

Затем автоматически или по кнопке **ENTER THE RUINED HALL** открыть финальную сцену.

Сцена представляет собой древний полуразрушенный зал:

- обрушенные каменные колонны;
- заросшие мхом стены;
- корни и лианы;
- лучи света через разрушенную крышу;
- каменная пыль и легкий туман;
- большое каменное изваяние в центре.

## 10. Каменное изваяние

На изваянии находятся три четко различимые пустые выемки:

```text
[ SLOT 1 ] [ SLOT 2 ] [ SLOT 3 ]
```

Рядом в случайном порядке располагаются три собранные руны. Перед каждым новым прохождением их порядок перемешивается.

Правильный порядок:

```text
Slot 1 → rune1.png
Slot 2 → rune2.png
Slot 3 → rune3.png
```

Игрок может устанавливать руны в любом порядке, но каждый слот принимает только правильную руну.

Поддержать:

- drag-and-drop мышью;
- Pointer Events для сенсорных экранов;
- установку руны кликом: сначала выбрать руну, затем выбрать слот;
- клавиатурное управление.

### Правильная установка

- руна примагничивается к центру слота;
- изображение точно помещается внутрь выемки;
- слот получает слабую зелено-золотую подсветку;
- проигрывается звук тяжелого каменного щелчка;
- установленная руна блокируется.

### Неправильная установка

- слот коротко подсвечивается приглушенным красным;
- руна возвращается в исходную область;
- правильно установленные руны остаются на месте;
- правильный ответ не показывается.

Сообщение:

> **The stone rejects this rune.**

## 11. Завершение квеста

Когда все три руны установлены правильно:

1. каменное изваяние активируется;
2. руны начинают мягко светиться;
3. по резным линиям изваяния проходит зелено-золотой свет;
4. сохраняется прогресс Jungle Code;
5. появляется надпись-кнопка:

   > **RETURN TO THE JUNGLE**

Кнопка не должна появляться до правильной установки всех трех рун.

При нажатии игрок возвращается на главную страницу:

```text
index.html
```

Возврат должен происходить только по действию игрока, без автоматического таймера.

## 12. Сохранение прогресса

После успешной установки всех рун сохранить:

```js
localStorage.setItem('jungleCodeCompleted', 'true');
localStorage.setItem('jungleCodeRunesActivated', 'true');
```

Также добавить достижение `code` в общий список:

```js
const achievements = JSON.parse(
  localStorage.getItem('expeditionAchievements') || '[]'
);

if (!achievements.includes('code')) {
  achievements.push('code');
}

localStorage.setItem(
  'expeditionAchievements',
  JSON.stringify(achievements)
);
```

Повторное прохождение квеста не должно удалять уже сохраненное достижение.

## 14. Критерии готовности

- [ ] Перед квестом доступны Easy, Medium и Hard.
- [ ] Выбранная сложность применяется ко всем трем вопросам.
- [ ] В каждом раунде показывается только один зашифрованный вопрос.
- [ ] Вопрос расшифровывается последовательно, буква за буквой.
- [ ] Пробелы и пунктуация не требуют ввода.
- [ ] Неправильная буква не сбрасывает уже расшифрованную часть вопроса.
- [ ] За первый вопрос выдается `rune1.png`.
- [ ] За второй вопрос выдается `rune2.png`.
- [ ] За третий вопрос выдается `rune3.png`.
- [ ] Используются изображения из папки проекта, а не условные символы.
- [ ] После получения трех рун открывается древний полуразрушенный зал.
- [ ] В зале присутствует каменное изваяние с тремя слотами.
- [ ] Руны перед финальной сценой перемешиваются.
- [ ] Каждый слот принимает только соответствующую руну.
- [ ] Правильно установленные руны остаются в изваянии.
- [ ] После установки всех рун появляется **RETURN TO THE JUNGLE**.
- [ ] По нажатию игрок возвращается в `index.html`.
- [ ] Завершение квеста сохраняется в `localStorage`.
