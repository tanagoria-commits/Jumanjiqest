# Expedition Vault — активация реликвии, звук и редизайн главного экрана

## 1. Активация реликвии и автоматический возврат

### Требуемое поведение

После правильной установки пятого фрагмента пазл считается завершённым.

Игрок не должен вручную нажимать кнопку возврата. Вместо этого необходимо показать короткую сцену активации реликвии, сохранить прогресс и автоматически вернуть игрока на главную страницу.

### Последовательность

```text
Последний фрагмент установлен
        ↓
Все части фиксируются
        ↓
Пазловые границы исчезают
        ↓
Показывается цельная реликвия
        ↓
Реликвия активируется
        ↓
RELIC AWAKENED
        ↓
Прогресс сохраняется
        ↓
Автоматический переход на главную страницу
```

### Визуальная активация

После сборки:

1. затемнить фон зала;
2. показать цельное изображение `assets/relic-transparent.png`;
3. постепенно усилить зелёное свечение камней;
4. добавить мягкое золотое свечение по контуру;
5. показать расходящиеся световые кольца или частицы;
6. немного увеличить реликвию;
7. показать заголовок:

> **RELIC AWAKENED**

Текст:

> **The Lost Temple has accepted you. The jungle path is open once more.**

### Сохранение

Сохранить прогресс до начала перехода:

```javascript
localStorage.setItem("lostTempleCompleted", "true");
localStorage.setItem("lostTempleRelicCollected", "true");
```

Добавить достижение:

```javascript
const achievements = JSON.parse(
  localStorage.getItem("expeditionAchievements") || "[]"
);

if (!achievements.includes("temple")) {
  achievements.push("temple");
}

localStorage.setItem(
  "expeditionAchievements",
  JSON.stringify(achievements)
);
```

### Автоматический переход

Через 2,5–4 секунды после начала активации перейти на главную страницу:

```javascript
setTimeout(() => {
  window.location.href = "index.html#games";
}, 3200);
```

Показать небольшой индикатор:

> **Returning to the jungle…**

Ручная кнопка может остаться только как резервный вариант, если автоматический переход не сработал.

## 2. Звуковая система

## 2.1 Фоновая музыка Lost Temple

Для первого квеста использовать файл:

```text
music1.mp3
```

Музыка должна:

- начинаться при входе игрока внутрь квеста;
- продолжаться на всех сценах Lost Temple;
- циклически повторяться;
- плавно начинаться;
- останавливаться при выходе из квеста;
- останавливаться перед автоматическим переходом на главную страницу;
- запоминать выбранную громкость;
- поддерживать включение и выключение.

HTML:

```html
<audio id="quest-music" src="music1.mp3" loop preload="auto"></audio>
```

### Ограничение браузеров

Большинство браузеров запрещают автоматическое воспроизведение музыки со звуком до первого действия пользователя.

Поэтому музыка запускается:

1. сразу при загрузке, если браузер разрешает autoplay;
2. если autoplay заблокирован — после первого нажатия **ENTER THE TEMPLE**;
3. после запуска музыка продолжает играть на всех сценах квеста.

```javascript
async function startQuestMusic() {
  try {
    await questMusic.play();
  } catch {
    // Воспроизведение начнётся после первого действия игрока.
  }
}
```

### Остановка

```javascript
function stopQuestMusic() {
  questMusic.pause();
  questMusic.currentTime = 0;
}

window.addEventListener("pagehide", stopQuestMusic);
```

Перед автоматическим переходом выполнить плавное затухание.

## 2.2 Управление музыкой

В правой части шапки квеста вместо простого `SOUND: ON/OFF` добавить компактную панель:

```text
♫  ─────●──  70%  🔊
```

Элементы:

- кнопка включения и выключения;
- ползунок громкости;
- отображение текущего процента;
- кнопка mute/unmute.

Диапазон:

```html
<input
  type="range"
  id="music-volume"
  min="0"
  max="1"
  step="0.05"
  value="0.55"
>
```

Сохранять настройки:

```javascript
localStorage.setItem("questMusicVolume", String(volume));
localStorage.setItem("questMusicMuted", String(muted));
```

Рекомендуемая начальная громкость — `0.45–0.6`, чтобы музыка не мешала заданиям.

## 2.3 Звуки интерфейса

Добавить короткие звуковые эффекты:

| Событие | Звук |
|---|---|
| Наведение на кнопку | Очень тихий деревянный или каменный щелчок |
| Нажатие кнопки | Короткий щелчок |
| Правильный ответ | Мягкий высокий тон |
| Неправильный ответ | Низкий приглушённый тон |
| Начало перетаскивания | Лёгкий металлический звук |
| Правильная установка фрагмента | Золотистый звон |
| Открытие дверей | Каменный скрежет |
| Активация реликвии | Короткий магический аккорд |

Если отдельных аудиофайлов пока нет, для простых сигналов можно использовать Web Audio API.

Звуки интерфейса должны учитывать общий mute-переключатель.

## 3. Редизайн главного экрана

## 3.1 Фоновое изображение

Для заднего фона главного hero-экрана использовать:

```text
1.png
```

Изображение должно:

- занимать всю hero-область;
- масштабироваться через `background-size: cover`;
- сохранять важную центральную часть карты;
- иметь тёмный градиент слева для читаемости текста;
- иметь лёгкое затемнение по краям.

Пример:

```css
.hero {
  background:
    linear-gradient(90deg, rgba(3, 12, 8, .96), rgba(3, 12, 8, .3)),
    linear-gradient(0deg, #07100c, transparent 35%),
    url("1.png") center / cover;
}
```

## 3.2 Боковое меню

Удалить вкладки:

- **Discover**;
- **Achievements**.

В обычном режиме оставить:

- **Legend**;
- **Quests**.

Соответствующие разделы Discover и Achievements можно скрыть из обычной навигации, но оставить доступными через Developer Mode для проверки.

## 3.3 Удаление кнопки

Убрать кнопку:

> **Choose your route**

После текста hero не должно оставаться пустого декоративного контейнера кнопки.

Переход к квестам выполняется через пункт **Quests** в боковом меню или прокруткой страницы.

## 4. Профиль игрока

В правом верхнем углу удалить:

> **Expedition active**

Вместо него показать профиль игрока:

```text
[avatar]  Explorer
          Jungle Newcomer  ▾
```

Минимальные элементы:

- круглый аватар;
- имя или роль игрока;
- текущий ранг;
- кнопка открытия меню.

Меню профиля:

- **View progress**;
- **Reset progress**;
- **Developer Mode**;
- **Close**.

Пока авторизации нет, использовать локальный профиль:

```javascript
const playerProfile = {
  name: "Explorer",
  avatar: "default",
  rank: "Jungle Newcomer"
};
```

Ранг зависит от количества завершённых квестов:

| Квестов завершено | Ранг |
|---:|---|
| 0 | Jungle Newcomer |
| 1 | Temple Pathfinder |
| 2 | Jungle Trailblazer |
| 3 | Legend of the Vault |

## 5. Прогресс вместо поиска

Удалить поисковую строку:

> **Search expeditions…**

На её месте показать прогресс из трёх звёзд:

```text
EXPEDITION PROGRESS     ★ ☆ ☆     1 / 3
```

Каждая звезда соответствует квесту:

| Звезда | Квест |
|---:|---|
| 1 | Lost Temple |
| 2 | Jungle Code |
| 3 | Hidden Trail |

До завершения:

```text
☆
```

После завершения:

```text
★
```

Для чтения прогресса использовать:

```javascript
const completed = {
  temple: localStorage.getItem("lostTempleCompleted") === "true",
  code: achievements.includes("code"),
  trail: achievements.includes("trail")
};
```

Прогресс должен обновляться при возврате с квеста без ручной перезагрузки.

## 6. Полноценный знак сторон света

Справа в hero-экране показать полностью прорисованный компас.

Он должен содержать:

- внешний круг;
- внутренние окружности;
- основную четырёхконечную розу ветров;
- дополнительные малые лучи;
- центральный медальон;
- подписи:
  - **N** — сверху;
  - **E** — справа;
  - **S** — снизу;
  - **W** — слева.

Компас лучше создать в SVG, чтобы он оставался чётким на любых экранах.

Пример структуры:

```html
<svg class="hero-compass" viewBox="0 0 240 240" aria-label="Compass rose">
  <circle cx="120" cy="120" r="104" />
  <circle cx="120" cy="120" r="82" />
  <text x="120" y="20">N</text>
  <text x="220" y="125">E</text>
  <text x="120" y="230">S</text>
  <text x="20" y="125">W</text>
  <!-- Лучи и центральный медальон -->
</svg>
```

Цвета:

- античное золото;
- тёмная бронза;
- слабое внутреннее свечение.

## 7. Сброс прогресса

В меню профиля добавить:

> **RESET PROGRESS**

Перед сбросом обязательно показать подтверждение:

> **Reset all expedition progress? All relics and achievements will be lost.**

Кнопки:

- **Cancel**;
- **Reset everything**.

При подтверждении удалить:

```javascript
localStorage.removeItem("lostTempleCompleted");
localStorage.removeItem("lostTempleRelicCollected");
localStorage.removeItem("expeditionAchievements");
```

Также удалить будущие ключи Jungle Code и Hidden Trail.

Не удалять настройки музыки, если пользователь отдельно не выбрал сброс настроек.

После сброса:

- обновить звёзды;
- вернуть начальный ранг;
- заблокировать полученные реликвии;
- закрыть меню профиля;
- показать сообщение:

> **Expedition progress has been reset.**

## 8. Developer Mode

Developer Mode нужен для просмотра любой части сайта без обязательного прохождения предыдущих этапов.

Переключатель находится в меню профиля:

```text
DEVELOPER MODE     OFF / ON
```

Состояние сохраняется:

```javascript
localStorage.setItem("developerMode", String(enabled));
```

### Возможности Developer Mode

- открыть любую сцену Lost Temple;
- перейти сразу к выбору сложности;
- открыть любое из пяти языковых испытаний;
- открыть двери храма;
- перейти прямо к пазлу;
- показать сцену активации реликвии;
- открыть Jungle Code;
- открыть Hidden Trail;
- просмотреть скрытые Discover и Achievements;
- временно отметить любой квест завершённым;
- очистить только тестовый прогресс.

### Панель разработчика

При включении показать компактную панель:

```text
DEV
├─ Main Hero
├─ Legend
├─ Quest Cards
├─ Lost Temple: Start
├─ Lost Temple: Difficulty
├─ Lost Temple: Trial 1–5
├─ Lost Temple: Doors
├─ Lost Temple: Relic Puzzle
├─ Lost Temple: Relic Awakened
├─ Jungle Code
├─ Hidden Trail
├─ Discover
└─ Achievements
```

Developer Mode не должен автоматически изменять постоянный пользовательский прогресс, если разработчик явно не выбрал соответствующее действие.

В интерфейсе должен отображаться заметный, но компактный индикатор:

> **DEV MODE**

## 10. Критерии готовности

### Реликвия

- [ ] После сборки запускается сцена активации.
- [ ] Цельная реликвия светится золотым и зелёным.
- [ ] Прогресс сохраняется до перехода.
- [ ] Игрок автоматически возвращается на главную страницу.
- [ ] Музыка плавно останавливается перед переходом.

### Звук

- [ ] В Lost Temple используется `music1.mp3`.
- [ ] Музыка запускается при входе или после первого действия.
- [ ] Музыка зациклена.
- [ ] Есть включение, выключение и регулировка громкости.
- [ ] Громкость сохраняется в `localStorage`.
- [ ] Музыка останавливается при выходе.
- [ ] Добавлены звуки кнопок и игровых событий.

### Главный экран

- [ ] Hero использует `1.png`.
- [ ] Expedition active заменена профилем.
- [ ] Поиск заменён прогрессом из трёх звёзд.
- [ ] Звёзды связаны с завершением квестов.
- [ ] Discover удалён из обычного меню.
- [ ] Achievements удалён из обычного меню.
- [ ] Choose your route удалена.
- [ ] Справа показан полный компас N/E/S/W.
- [ ] В профиле есть подтверждаемый сброс прогресса.
- [ ] После сброса интерфейс обновляется.
- [ ] Developer Mode позволяет открыть любую сцену.
- [ ] Developer Mode не изменяет прогресс без отдельного действия.
